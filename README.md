
# LAB 3 - GIÁM SÁT MÔI TRƯỜNG BỂ NUÔI THỦY HẢI SẢN

## 1. Giới thiệu
Dự án thiết kế hệ thống tự động giám sát các thông số môi trường cho bể nuôi thủy hải sản.

## 2. Cấu trúc thư mục
- Bao_cao: Báo cáo thực hiện dự án.
- ESP32: Chương trình điều khiển ESP32.
- Images: Hình ảnh của dự án.
- Web: Giao diện giám sát trên website.
- Wokwi: Mô phỏng hệ thống.

## 3. Chức năng
- Thu thập dữ liệu cảm biến.
- Giám sát thông số môi trường.
- Hiển thị dữ liệu trên giao diện Web.
- Hỗ trợ theo dõi hoạt động hệ thống.

## 4. Công nghệ sử dụng
- ESP32
- C++
- HTML, CSS, JavaScript
- IoT
